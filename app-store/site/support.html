Plan work days without changing a deadline

Open the work-day or deadline control at the top of a task. In the Work days tab, select any days you want to work on it; they can be nonconsecutive and span several months. In the Deadline tab, choose its one final deadline. Save applies both; Cancel, Escape, or tapping outside leaves the previous schedule unchanged. Clear affects only the selected tab.

Priority, workflow status, and completion are separate controls. Use High, Medium, Low, or No priority to highlight what matters, move tasks through your board's statuses, and use Plan your day to review approaching deadlines and in-progress work.

See Apple and Google calendars

  1. In the native app, open Settings → Calendars → Connect calendars.
  2. Allow full calendar access when the operating system asks, then choose which calendars to show.
  3. Open Calendar and switch between Month, Week, and Day to see events alongside task work days and deadlines.

GreenDay uses the accounts already configured in Apple Calendar, including iCloud and Google. If an account is missing, add or enable it in Apple Calendar or your device's calendar account settings, then refresh calendar access in GreenDay. There is no separate Google sign-in inside GreenDay. The provider controls sync timing; a local save does not guarantee that another device has received the change.

If access was declined, allow it in the device's privacy settings and reconnect. Task editing still works without calendar access. Read-only calendars show events but cannot accept changes. Browser previews show task dates but cannot connect to native calendar accounts.

Link an event to a task

Use Link event in task details or Link task in an event. Schedule work session lets you create a timed event from a task after reviewing its title, calendar, and times. A link does not change the task's work days or deadline. Unlink removes the association without deleting the event; deleting or trashing the task also leaves the provider's event in place.

When a calendar is unavailable, a link can show its last saved details. Refresh or reconnect before changing the event. Recurring event edits and deletions apply to the selected occurrence. If an event moved or a link cannot be resolved, choose the intended event again rather than assuming its old saved details are current.

Use the same workspace on your devices

  1. On each device, open Settings → Storage & sync → Choose workspace folder. On first launch, you can also use the workspace connection prompt.
  2. Select the same folder in iCloud Drive using the same Apple Account.
  3. Allow iCloud Drive to finish transferring files, then reopen the task on the other device.

The app saves locally first. A saved message does not mean every file has already reached another device. If a file is still downloading, keep its workspace available and try again after the file provider finishes.

The Mac App Store version starts with a private local workspace. To use files from an earlier GreenDay or Daymark installation, choose that existing workspace folder yourself. The app does not search outside its sandbox for your old files.

The app is now named GreenDay, but existing workspace folders and internal identifiers remain unchanged. Keep using the same folder even if it is named Daymark; renaming the app does not require moving your tasks.

Keep a backup

Settings → Export task data creates a copy of your task records. To back up attachment files and recovery history too, copy the entire workspace folder. Its current location is shown in Settings.

Edit equations and checklists

The note editor has a left gutter instead of a fixed formatting bar. Use + beside the current paragraph, or type / on a new line, to choose a note element. The active heading shows H1, H2, or H3 in the gutter. On touch screens, Done dismisses the software keyboard.

Tap or click an equation to reveal its LaTeX. With a hardware keyboard, arrow keys move into and out of equation source. Enter continues a list or checkbox; Enter on an empty item exits the list. Open checkboxes gathers unfinished steps from active tasks. It hides steps in completed or trashed tasks without marking them checked in the note; reopening a task brings its unfinished steps back.

If Vim mode is on, press i to type and Escape to return to Normal mode. Shift+J joins lines within editable text or the current equation source. You can turn Vim mode off in Settings → Editor.

Add images and documents

Paste an image to place it in the note, then select it to resize, crop, or delete it. On Mac, dropping a file into a note adds a filename link at the indicated position. File drops support documents as well as images, up to 25 MB per file. Use Insert image in the note element menu when you want an image displayed inline. The system file picker remains available for choosing a file without dragging.

Open an image link to preview it. PDFs use the native document viewer on Mac and iPhone, and other files open in an app that supports them. Removing a link from the note does not erase the copied file from older task revisions or backups.

Adjust the workspace

On a desktop-sized window, drag the divider beside the navigation pane or task detail pane. The dividers also support arrow keys; double-click or Home restores their default widths. These preferences are remembered on the current device. Compact task rows leave more room for notes and calendar content.

Report an issue

Include your device, operating system version, app version, what you tried, and what happened. A short example using fictional tasks is usually enough. Do not send your full workspace or private attachments unless you deliberately choose to share them for a specific support request.

Remove your data

Trash is recoverable. For permanent removal, close the app on every device using the workspace and delete the workspace folder, its recovery history, and any exports or copies you made. See the privacy policy for file-provider and backup considerations.

Deleting the workspace or uninstalling GreenDay does not remove events from Apple Calendar or their providers. Delete those events separately if desired, and revoke calendar access through the device's privacy settings.
