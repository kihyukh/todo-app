# Screenshot capture plan

Capture the actual release app in a fresh workspace with fictional tasks. Do not use the publisher’s migrated tasks, attachments, or private account information. The final app name must be consistent with the listing.

| Shot | Useful content |
| --- | --- |
| Today | Three deliberately chosen tasks; show that a deadline can be later than the do date |
| Rich task note | A short research example with an equation, link, image, and checkbox |
| Open checkboxes | Unfinished steps from two fictional tasks, linked to their originals |
| Board | One small project with a few tasks in distinct columns |

Use opaque PNG or JPEG. Apple accepts one to ten screenshots. For iPhone, a supported 6.9-inch slot such as 1320 × 2868 portrait is a practical starting point; if iPad support remains enabled, also capture its required large-display slot. For a Mac submission, use a supported 16:10 size such as 1440 × 900 or 2880 × 1800. Verify the current device slots before upload. [Apple screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/)

Screenshots are still required; this file is a shot list, not a claim that approved screenshots exist.
